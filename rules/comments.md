# Comment Rules

1. **Keep comments to 1 line. Never exceed 2 lines.** If a comment needs more, the code is unclear — rename, extract, or simplify instead of explaining.
2. Write comments only when the *why* is not obvious from the code. Do not narrate what the next line does.
3. Prefer a single `//` line. A second line is allowed only when one line would be cramped or lose meaning. Do not use block comments (`/* */`, JSDoc, or `/** */`) for ordinary notes.
